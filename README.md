# Автоматичний моніторинг офіційних Telegram-каналів Дніпропетровщини

Це перша частина постійної схеми підготовки довідки. Збирач працює у GitHub
Actions кожні 30 хвилин, накопичує дописи протягом доби та не потребує входу
в Telegram. Телефон після одноразового налаштування може бути вимкнений.

Щоранку файл `data/report_input.md` автоматично фіксує останнє повністю
завершене вікно від 08:00 попереднього дня до 08:00 поточного дня за Києвом.
Заплановане завдання ChatGPT читає саме цей файл, звіряє факти з іншими
офіційними джерелами та формує довідку у погодженому форматі.

## Канали

- `@adm_dp` — Дніпропетровська ОВА
- `@dsns_telegram` — ДСНС України
- `@SBUkr` — СБУ
- `@DniproCityOfficial` — офіційний канал міста Дніпра
- `@gunpvdp` — поліція Дніпропетровської області
- `@cek_info` — ЦЕК

Список можна змінювати у `channels.txt`.

## Результати

- `data/posts.json` — короткий технічний буфер дописів за останні 72 години;
- `data/latest.md` — зручний текст дописів за останні 48 годин;
- `data/report_input.md` — дописи лише за останнє завершене вікно 08:00–08:00;
- `data/status.json` — час перевірки та стан доступу до кожного каналу.

Дані старші за 72 години видаляються автоматично під час чергового запуску.
Це залишає запас на випадок затримки GitHub і не створює постійного архіву.

## Запуск

Після завантаження файлів у публічний GitHub-репозиторій відкрийте вкладку
**Actions**, виберіть **Collect Telegram posts**, натисніть **Run workflow**.
Після першої успішної перевірки подальші запуски виконуються автоматично.

Розклад GitHub може запускатися із затримкою. Час останньої фактичної перевірки
завжди записаний у `data/status.json`.

## Оперативні повідомлення протягом дня

Збирач також може надсилати у Telegram повідомлення про нові резонансні події:
атаки, обстріли, влучання, загиблих або поранених, евакуацію, масштабні пожежі,
аварійні відключення, перекриття, мінування та інші визначені безпекові події.
Для загальноукраїнських каналів сповіщення надсилається лише за наявності у
тексті згадки Дніпра, Дніпропетровщини або населеного пункту області.

Для цього створіть окремого бота через `@BotFather`, відкрийте чат із ботом і
натисніть **Start**. У репозиторії відкрийте **Settings → Secrets and variables →
Actions** і додайте два секрети:

- `TELEGRAM_BOT_TOKEN` — токен, отриманий від `@BotFather`;
- `TELEGRAM_CHAT_ID` — числовий ідентифікатор вашого чату з ботом.

Після першого запуску бот надішле тестове підтвердження. Далі перевірка йде
кожні 30 хвилин, а `data/alert_state.json` запобігає повторному надсиланню одного
допису. Секрети не записуються у файли репозиторію.

## Посилання для ранкової довідки

Після створення репозиторію адресу даних потрібно додати до завдання ChatGPT:

`https://raw.githubusercontent.com/ІМʼЯ-КОРИСТУВАЧА/НАЗВА-РЕПОЗИТОРІЮ/main/data/report_input.md`

Для контролю повноти також використовується:

`https://raw.githubusercontent.com/ІМʼЯ-КОРИСТУВАЧА/НАЗВА-РЕПОЗИТОРІЮ/main/data/status.json`

Збирач читає лише загальнодоступні сторінки `t.me/s/...`. Він не використовує
номер телефону, `api_id`, `api_hash`, пароль або Telegram-сесію.

## Повна автоматизація

Після створення репозиторію передайте його адресу в чат. Тоді до наявного
щоденного завдання ChatGPT буде додано дві точні адреси: `report_input.md` і
`status.json`. Після цього участь людини у щоденному зборі та формуванні довідки
не потрібна. Нові канали надалі додаються одним рядком у `channels.txt`.
